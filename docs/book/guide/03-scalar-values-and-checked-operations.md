# Scalar values and checked operations

SLIM's scalar core is intentionally small: `Bool`, `I64`, `U8`, and `Unit`,
with explicit built-ins for arithmetic, comparison, Boolean logic, conversion,
and I/O.

## Scalar types

`Bool` contains `true` and `false`. `I64` is a signed 64-bit integer. `U8` is an
unsigned byte. `Unit` is the result type for operations whose purpose is an
effect. There are no implicit numeric conversions.

## Checked arithmetic

Arithmetic is called explicitly:

```slim
let sum: I64 = i64.add(left right)
```

`i64.add`, `i64.sub`, and `i64.mul` trap on overflow. Division and remainder
trap on a zero divisor; the minimum-integer divided by `-1` also traps.

<!-- slim-fixture: overflow -->

A runtime trap exits with status `70` and a stable message. It is observable
behavior: reduction and optimization may not erase or reorder it.

## Comparisons and Boolean operations

Integer comparison built-ins return `Bool`. Boolean operations are ordinary
strict calls, not hidden short-circuit control flow. Arguments are evaluated
left to right before the operation.

## Explicit conversion

`u8.to-i64` widens a byte. `i64.to-u8` checks that the value is within the byte
range and traps otherwise.

## Compiler guarantees

The checker rejects argument and result type mismatches. The runtime cannot
silently wrap checked arithmetic. The analyzer may remove a trap hazard only
when it has a positive fact for that exact checked node; missing or exhausted
evidence remains unknown.

## Deliberate omissions

There are no implicit conversions, operator aliases, unchecked arithmetic,
floating-point values, or user-selectable overflow modes in the accepted
surface. The exact built-in list is generated by `./slimc builtins` and recorded
in [Core](../../CORE.md).
