# Expressions and evaluation order

This chapter specifies construction, calls, built-ins, projection, mutation,
matching, and the observable order in which their operands are evaluated.

## Name and literal expressions

A name resolves lexically to one declaration or binding. Literals have their
statically required scalar type. There is no dynamic name lookup or contextual
implicit conversion.

## Calls

A call uses `callee(arguments...)`, with whitespace and no commas between
arguments. The checker validates callee identity, arity, operand types,
ownership transfer, `inout` eligibility, borrow exclusivity, and effect
compatibility.

Operands evaluate left to right. Nested calls preserve that order in generated
C, including any effects, traps, moves, mutations, or allocation failures.

## Construction and projection

`make` constructs a record with every field in declared order. `get` projects a
known record field. `case` constructs a known variant alternative with its
exact payload.

`set name = value` is the canonical visible rebinding form. It checks unique
lexical access and the assigned value type and produces no hidden copy. Record
projection remains read-only; there is no separate field-assignment syntax.

## Built-ins

Arithmetic, comparison, Boolean, conversion, storage, and host operations are
explicit built-in calls. Checked arithmetic, conversion, and indexes trap on
their documented invalid domain. Allocation and host operations require their
declared effects.

The exact accepted names are generated by:

```sh
./slimc builtins
```

## Match expressions

`match` evaluates its scrutinee once, selects one exhaustive Boolean or variant
arm, binds any payload, and produces the arm result. All arms agree on one
result type. Pattern rules are in
[patterns and exhaustiveness](05-patterns-and-exhaustiveness.md).

## Observable behavior

Output, host calls, traps, allocation failure, moves, mutation, borrows, and
destruction order are observable constraints on rewriting and lowering. A
missing proof never permits the compiler to erase one.
