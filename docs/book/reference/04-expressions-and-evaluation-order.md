# Expressions and evaluation order

This chapter specifies construction, calls, built-ins, projection, mutation,
matching, and the observable order in which their operands are evaluated.

## Name and literal expressions

A name resolves lexically to one declaration or binding. Literals have their
statically required scalar type. There is no dynamic name lookup or contextual
implicit conversion.

## Calls

A call uses `callee(arguments...)`, with required commas between arguments.
The checker validates callee identity, arity, operand types,
ownership transfer, `inout` eligibility, borrow exclusivity, and effect
compatibility.

Operands evaluate left to right. Nested calls preserve that order in generated
C, including any effects, traps, moves, mutations, or allocation failures.

## Construction and projection

`Pair(left: 1, right: 2)` constructs a struct with every field in declared
order. `pair.left` projects a known field. `Maybe::Some(value)` constructs a
known enum case with its exact payload.

`name = value` is the canonical visible rebinding form for `var` and mutable
parameters. It checks unique lexical access and the assigned value type and
produces no hidden copy. Struct projection remains read-only.

## Built-ins

Arithmetic, comparison, and Boolean logic use canonical operators. Conversion,
storage, and host operations are explicit built-in calls. Checked arithmetic,
conversion, and indexes trap on their documented invalid domain.

The exact accepted names are generated by:

```sh
./slimc builtins
```

## Match expressions

`if`/`else` handles Boolean selection. `match` evaluates an enum scrutinee once,
selects one exhaustive arm, binds its payload, and produces the arm result.
All branches agree on one result type. Pattern rules are in
[patterns and exhaustiveness](05-patterns-and-exhaustiveness.md).

## Observable behavior

Output, host calls, traps, allocation failure, moves, mutation, borrows, and
destruction order are observable constraints on rewriting and lowering. A
missing proof never permits the compiler to erase one.
