# Portable bootstrap seed

`slimc-seed.c` is the generated, deterministic C11 fixed point of
`selfhost/slim.project`. It is a trust artifact, not maintained compiler source.
Compiler changes belong in the SLIM modules under `selfhost/`; regeneration
must replace this file mechanically after all cutover gates pass.

Provenance:

- source milestone: Core 1A direct typed reduction plus the accepted D0027 and
  D0028 architecture decisions;
- generated by: the native compiler built from the preceding portable seed;
- fixed-point proof: stage 2 and stage 3 emitted identical C;
- current exact size: 1,141,206 bytes;
- SHA-256:
  `aeef245413e5766d86ca84efdcea63f3b29694728c4b9a4cf774ce387bfe5572`;
- captured: 2026-07-22 on macOS arm64;
- required target: portable C11 plus `runtime/slim_rt.c` and
  `runtime/slim_rt.h`.

The root bootstrap command verifies the recorded digest before compiling the
seed. It then asks the seed compiler to compile `selfhost/slim.project`, builds
that result, asks the new compiler to compile the project again, and accepts
the bootstrap only if the two generated C files are byte-identical. The seed
is never trusted merely because it compiles.

Do not check in a platform-native compiler binary. Git history retains the
former Rust stage-0 source for forensic comparison and disaster recovery.

After a compiler change written in existing SLIM Core, run
`scripts/refresh-bootstrap-seed.sh`. It uses the current seed to produce three
generations and replaces the tracked seed only when generations 2 and 3 are
identical. The ordinary bootstrap remains strict and never refreshes trust
artifacts implicitly.
