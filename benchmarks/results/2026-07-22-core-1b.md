# Core 1B bounded-program evidence

Date: 2026-07-22
Baseline commit: `62f44fa`
Host: Apple arm64, Darwin 25.3.0
Toolchain: Apple Clang 21.0.0; Rust/Cargo 1.96.0

## Outcome

Core 1B adds no SLIM syntax, type, effect, built-in, runtime ABI, or second
program representation. The production implementations of quality analysis,
reduction records/replay, finite equivalence, and structural editing are SLIM
modules. Rust remains benchmark, conformance, and governance infrastructure.

The portable compiler seed is 1,364,504 C bytes with SHA-256
`096b0eb9fd5409d6a27e37e9f463be591e8df27606b8db9754262d0034c13d89`.
Bootstrap generations reproduce those bytes exactly.

The release tests cover exact and unknown state models, ownership pressure,
totality classification, deterministic proof records, independent normal-form
verification, equivalent/different/unsupported finite functions, the first
canonical counterexample, valid/malformed/type-invalid edits, and rejection of
the edit protocol as executable SLIM. Conformance runs 62 fixtures plus 2,000
deterministic malformed mutations; every new command receives 100 random
malformed probes in addition to curated cases.

## Default and proof scaling

Command:

```text
cargo run --release --quiet --bin slim-bench -- scaling --quick
cargo run --release --quiet --bin slim-bench -- reduction --quick
```

Process-level medians, microseconds:

| declarations | bytes | check | emit C | reduce | analyze v2 | proof |
|---:|---:|---:|---:|---:|---:|---:|
| 250 | 17,612 | 3,851 | 9,034 | 5,486 | 5,327 | 5,944 |
| 500 | 35,362 | 5,783 | 22,831 | 8,471 | 8,095 | 9,945 |
| 1,000 | 70,862 | 9,446 | 71,860 | 15,271 | 14,796 | 18,055 |
| 2,000 | 143,862 | 16,707 | 254,172 | 27,535 | 27,061 | 33,594 |

Across the 8x declaration range, the measured process-level exponents are
0.706 for ordinary checking, 0.775 for reduction, 0.782 for analysis, and
0.834 for proof discovery. Each is below the repository's 1.25 gate. Analysis
output is intentionally linear in declarations (1,131,171 bytes at 2,000
generated functions); proof output remains bounded by 64 sites.

These are local regression measurements, not universal compiler-speed claims.
Native C emission still dominates large clean builds and was deliberately not
optimized in this milestone.

## Agent proxy benchmark

Command:

```text
cargo run --release --quiet --bin slim-bench -- agent
```

The fixture is one matched unknown-operation repair. `model proxy` is exactly
`ceil(source bytes / 4)` and is not a tokenizer or model-success measurement.
Feedback is the median of five compiler processes.

| language | broken/fixed bytes | broken/fixed neutral tokens | broken/fixed model proxy | remove/insert bytes | diagnostic bytes | broken/fixed accepted | broken/fixed feedback us |
|---|---:|---:|---:|---:|---:|---:|---:|
| SLIM | 132 / 138 | 44 / 47 | 33 / 35 | 7 / 13 | 51 | false / true | 16,207 / 15,040 |
| C11 | 99 / 91 | 29 / 27 | 25 / 23 | 14 / 6 | 242 | false / true | 28,312 / 25,461 |
| Rust | 96 / 88 | 33 / 31 | 24 / 22 | 14 / 6 | 319 | false / true | 37,835 / 32,255 |

This fixture does not show a token-size advantage for SLIM: its canonical call
and type spelling make the fixed source larger than the matched C and Rust
programs. It does show a smaller removed span and shorter diagnostics on this
machine. Neither observation establishes that an LLM writes or repairs SLIM
more successfully. Runtime and binary-size comparisons remain the independent
`slim-bench compare` suite.

## Reproduction and limits

The complete gate is:

```text
./scripts/verify.sh
```

Exact equivalence applies only to effect-free Boolean subjects using the
documented supported forms in the eight-input, 256-expression-token domain.
Quality reports do not
infer application invariants or a universal score. Totality becomes `unknown`
when calls or recursion are present. Edit node indices are stable only within
the exact canonical source supplied with the patch. Reduction records describe
at most 64 directly justified source sites; verification independently
recomputes the unique bounded normal form.
