# Core 0.3 freeze evidence

Date: 2026-07-21

Environment: Apple M1 Max (10 cores, 64 GB), macOS 26.3 / Darwin 25.3.0
arm64, rustc 1.96.0, Apple clang 21.0.0.

## Release gate

`./scripts/verify.sh` passes from the freeze tree. It covers:

- `cargo fmt --check` and Clippy for all targets with warnings denied;
- 61 Rust tests;
- feature and Rust-budget governance;
- 52 standalone/project differential fixtures, all at self-host parity and
  none deferred;
- byte-identical stage-2 and stage-3 output: 592,704 generated C bytes;
- scaling, incremental-work, persistent-cache, and worker-variance assertions;
- native `vector_sum` execution under AddressSanitizer and
  UndefinedBehaviorSanitizer.

## Self-host process timings

The following are medians of 21 fresh process executions after three warmups.
The harness used `time.perf_counter_ns`, captured stdout and stderr, and
required a successful exit for every sample. Times include startup, source and
cache reads, and generated output capture; they exclude compiling generated C.

| Scenario | Median ms | Minimum ms | Maximum ms | Stdout bytes |
| --- | ---: | ---: | ---: | ---: |
| Basic two-module clean compile | 2.147 | 1.998 | 2.889 | 1,386 |
| Twelve-module compiler clean compile | 322.838 | 321.291 | 326.007 | 592,704 |
| Twelve-module compiler validated cache hit | 7.796 | 6.088 | 21.775 | 592,705 |
| Basic-project private-edit session | 2.538 | 2.073 | 8.290 | 8 |

The cache-hit output has a one-byte `H` transport marker followed by the exact
clean artifact. The session output is the exact work vector `1 1 1 1` plus a
newline. Cache bytes are produced and validated by SLIM; the conformance
harness only persists the emitted entry because Core 0.3 deliberately has no
general file-write primitive.

## Larger synthetic evidence

The committed stage-0 frontend results in `2026-07-21-scaling.tsv` reach 8,000
declarations / 581,862 source bytes at 13.126 ms for checking and 19.539 ms for
C emission. `2026-07-21-incremental.tsv` proves zero declaration work for an
unchanged 8,001-declaration program, one declaration of work for a private
body edit, two for a leaf-interface edit, and the exact 4,001-declaration
reverse closure for a central interface edit. `2026-07-21-project.tsv` records
module/declaration work, persistent hits, and worker-width equality over wide
and deep generated graphs.

## Claim boundary

Core 0.3 completes the SLIM-owned modular compiler/query/cache/scheduling
architecture. It does not yet satisfy the final performance ambition: a clean
self-compile is hundreds of milliseconds, not single-digit milliseconds. Its
scheduler produces deterministic bounded dependency batches but executes them
through the serial oracle; Core has no concurrency runtime, so no parallel
speedup, race-freedom theorem, or deadlock-freedom theorem is claimed. General
lifetime inference, typed optimization, quality grading, semantic
equivalence, and optimal reduction remain later milestones.
