# Core 1L compatibility and release stabilization

Date: 2026-07-23
Version: 1.0.0
Decisions: D0082, D0083
Target: Darwin 25.3.0 arm64
C compiler: Apple Clang 21.0.0

## Accepted boundary

Core 1L adds no source form, built-in, effect, unsafe path, backend, or
dependency. It freezes the exact existing surface and project ledgers,
diagnostic JSON schema 1, analysis schema 7, cost-vector schema 1, equivalence
schema 2, reduction-proof schema 2, structural-edit schema 1, project and
interface schema 1, and runtime ABI 1.

`VERSION` is the sole compiler-version source. Generated C contains a static
runtime ABI assertion. Unknown report schemas are rejected; validated caches
remain rebuildable evidence rather than compatibility-stable program
artifacts.

## Reproduction

```text
./scripts/verify-1.0.sh
./scripts/package-release.sh build/release
```

The first command runs repository, clean-package, tutorial, route, metadata,
surface, link, and website build checks. The second produces
`build/release/slim-1.0.0.tar.gz` and its SHA-256 file from a clean committed
tree.

## Honest limits

Darwin/arm64 with Apple Clang is the validated release platform. Portable C11,
serial fallback, and POSIX worker paths remain designed for more targets, but
no unexecuted target is claimed. General equivalence, global optimal
reduction, unrestricted host access, async task state, LLVM, and a second
executable IR remain outside SLIM 1.0.
